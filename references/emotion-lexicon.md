> **姿态复合词使用条件（v2.9.0 标注）**：上表末尾 4 词（克制中的温情/冷峻中的悲悯/叙述性冷漠/反讽性平静）是「叙述姿态 × 底色情感」的复合表达，**仅当文本存在明显的表面笔调与底色情感冲突时使用**（如叙述者用平静口吻讲述残酷事件）。普通单层情感一律用基础层/文学扩展层词，不要因文风克制而误用姿态词。

> **极性判定规则**：上表极性为**缺省映射**（与 D04.core → polarity 同构）。写 `primary.polarity` 时依据**本段文本情感语义**；无特别张力按缺省写；表面与底色冲突（克制中的温情/反讽性平静等词本身已含 tension）按上表写 mixed。

## 三、复合情感表达规则

- **`primary`** = 本段**主位情感**（同一情感在 intensity 上占主导者），永远只有一个。
- **`secondary`** = 与主位同时在场、可单独分离的次要情感（强度低于 primary 或并列但非主位）。**已经固化为词的复合**（悲欣交集/爱恨交织/苦乐参半）直接用该词做 primary，不再拆 secondary。
- **冲突处理**：正负同时在场且无一个占明显主导 → 用混合词（悲欣交集等）或 primary 取强度更高者、secondary 记录另一方。
- **弧（arc）**：段内情感**发生位移**时填（如「得知消息」前 3 后 7）。无位移（整段单一基调）→ `arc: null`。

## 四、词表演化协议（自适应层）

| 事件 | 动作 |
|:--|:--|
| 同一情感语义在产物中出现 ≥ 3 次且词表无词 | 记入候选，随版本发布正式入表 |
| 新增候选与既有词近义（语义重复） | 不新增，提示标注者用既有词 |
| 词表总量 | 控制 50–80 词；超 80 触发「基元归约审查」（扩展词必须能归约到 8 基元之一，不能的移除） |

### 四.b 基元归约审查协议（v3.2.0 / ADR-012，引入 DLUT 21 小类作中文归约目标）

> **背景**：词表超 80 词触发审查时，仅用 Plutchik 8 基元（喜悦/悲伤/愤怒/恐惧/惊讶/期待/厌恶/信任）做归约目标，对中文文学情感粒度偏粗（如"怅惘/物哀/苍凉"都归"悲伤"）。v3.2 引入**大连理工《情感词汇本体》7 大类 21 小类分类体系**作为中文归约的中间层，8 基元仍为最终归约底线。**只引用分类体系，不引入数据全文**（DLUT 数据仅本地运行，见 README 八）。

**审查规则（超 80 词时对每个新增候选执行）**：

| # | 检查 | 判定 |
|:--|:-----|:-----|
| 1 | 候选词能否归入 DLUT 21 小类之一？ | 否 → **移除**（非中文情感词） |
| 2 | 该小类归约到哪个 D19 基元？ | 小类→基元映射见下表 |
| 3 | 该基元下是否已有同义 D19 词？ | 是 → **不新增**（语义重复） |
| 4 | 通过 1-3 → 记入候选 | 随版本发布入表 |

**DLUT 21 小类代码表（分类体系引用，数据本地运行）**：

| 大类 | 小类代码 | 小类名 | 归约基元 |
|:----:|:--------:|:------|:--------|
| 乐 | PA / PE | 快乐 / 安心 | 喜悦 |
| 好 | PD / PH / PG / PB / PK | 尊敬 / 赞扬 / 相信 / 喜爱 / 祝愿 | 信任（PG）；喜悦（PB）；其余按词定 |
| 怒 | NA | 愤怒 | 愤怒 |
| 哀 | NB / NJ / NH / PF | 悲伤 / 失望 / 内疚 / 思念 | 悲伤 |
| 惧 | NC / NI | 恐惧 / 慌 | 恐惧 |
| 恶 | NE / NG / ND / NK / NL / NM(NN) | 烦闷 / 羞 / 憎恶 / 妒忌 / 怀疑 / 贬责 | 厌恶（NE/ND/NK/NL/NM）；羞耻（NG） |
| 惊 | PC | 惊奇 | 惊讶 |

## 五、强度与表达映射速查

| intensity | 对应 D04 锚点档位（emotion-anchors.md） | expression 判断 |
|:--:|:--|:--|
| 1-3 低 | 微微皱眉/轻叹/下意识动作 | 通常 `direct: false`，靠环境/动作侧面烘托 |
| 4-6 中 | 深吸气/声音发抖/眼眶湿 | `direct` 与 `indirect` 可并存 |
| 7-8 高 | 瘫坐/歇斯底里/胸口重锤 | 语言碎片化、动作大量、常带直接情感词 |
| 9-10 极高 | 崩溃/毁灭性 | 极端比喻、幻觉化、句子极短 |
