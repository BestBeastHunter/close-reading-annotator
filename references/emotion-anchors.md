# references/emotion-anchors.md — 情绪强度校准锚点 v2.6.0

> **本文件是 D04.intensity（情绪强度 1-10）的唯一真源。**
> SKILL.md 内联只给 4 档摘要，判断犹豫时请直接翻本文件。
> 判定步骤：①挑核心情绪（D04.core）；②在本文件下面找最贴近情绪分组的锚点；③看你的文本描述落在哪个强度档位。
> 如果某段描述的强度和本文件锚点差 ≥2 档，视为置信度过低，`confidence.per_dimension.D04` 要降到 ≤ 0.7，并在 alternatives 里放替代强度。

---

## 强度判定总原则

| 强度档 | 主观感 | 外显行为关键词 | 文学手法特征 |
|:------:|:------:|:-------------|:-----------|
| **1-3 低** | 几乎无生理反应，只是「心里有一点」 | 微微皱眉、轻叹、语气略变、下意识动作 | 叙事侧面暗示而非直接描写；环境描写烘托为主 |
| **4-6 中** | 有可感知的生理反应，但仍能自我控制 | 深吸一口气、声音发抖但忍住、眼眶微湿、脚步虚浮 | 直接描写心理感受 + 少量肢体动作；仍可理性对话 |
| **7-8 高** | 难以自控、生理反应强烈 | 瘫坐、歇斯底里、胸口重锤、失声呜咽、手抖不止 | 大量肢体+生理细节描写；语言碎片化；对话被情绪打断 |
| **9-10 极高** | 临界/崩溃/毁灭性情绪 | 撕心裂肺地嚎哭、血液凝固、万念俱灰、晕倒、死亡冲动、失去意识 | 用极端比喻、幻觉化描写；句子极短；人称/视角模糊 |

## 情感极性判定（v2.6.0 新增 D04.polarity，必填）

> 本文件是 D04.polarity 的判定真源。v2.6.0 产物该字段**必填**——四值全覆盖，省略=校验非法；拿不准时按下方「core → 极性」缺省映射兜底，不省略。

**极性由段落文本的情感语义决定，不由情节走向/文风推导。** 对照 D04.core 的缺省映射（core 定了、无特殊反讽张力时按此写）：

| 极性 | 典型 core | 说明 |
|:----:|:---------|:----|
| positive | 喜悦 / 希望 / 信任 / 宽恕 | 正向情绪主调 |
| negative | 悲伤 / 愤怒 / 恐惧 / 绝望 / 背叛 / 屈辱 / 焦虑 / 孤独 / 嫉妒 / 贪婪 / 复仇 | 负向情绪主调 |
| neutral | 平静 | 无显著正负偏向；信息陈述、旁观叙述亦可 neutral |
| mixed | 悬疑 / 释然 / 复合功能段 / 反讽张力 | 情绪两面并存，或"悲中带喜 / 喜中含刺"的复杂段落 |

**判定步骤（四值全覆盖，不得省略）**：
1. 段落情绪主调清晰 → 直接写对应极性；
2. **多重情绪冲突或反讽**（表面喜悦、底色悲凉）→ 写 `mixed`；
3. 仍拿不准 → 回到上表「core → 极性」缺省映射兜底：core 定了极性基本定，仅明显反讽张力才偏离映射。宁用 `neutral`/`mixed` 兜底，也**不要省略**（省略会被 v2.6.0 校验拒绝）。

### A. 希望 vs 绝望

| 强度 | 锚点描述（从典型文学作品抽取） |
|:----:|:----------------------------|
| 2 希望 | 「他心里掠过一丝光亮——也许她会回信呢。」日常里的小期待，没有任何证据支撑的微弱乐观 |
| 4 希望 | 「拿到那封信的一刻，他深吸一口气，手微微发抖——如果这是真的，一切都要不同了。」有具体证据支撑，仍在克制 |
| 6 希望 | 「他跑过街角，远远望见她站在路灯下，眼泪一下子涌上来——原来没有什么不可能。」强烈的情感冲击，但仍能控制行为 |
| 8 希望 | 「十四年了……他推开那扇门，看到那个熟悉的背影，双膝一软，跪倒在地——'我还以为这辈子都不会再有了。'」 |
| 2 绝望 | 「他叹了口气，把信揉成团丢进纸篓——果然又被拒了。」日常挫折后的淡淡失落 |
| 4 绝望 | 「他在走廊站了很久，窗外的雨一下没停。也许，本来就没有什么以后。」无力感持续，开始对未来悲观 |
| 6 绝望 | 「医生摘下口罩，摇了摇头。他整个人靠在墙上，慢慢滑坐在地，连呼吸都觉得累。」 |
| 8 绝望 | 「他看着那幅空牢房。十四年前，他从这里带走了一个年轻人，今天——那副镣铐还在原地。他终于明白，有些债一辈子都还不清。」 |
| 10 绝望 | 「他打开窗，望着下方二十层楼的高度，嘴角浮起一个平静的微笑——'终于自由了。'」（万念俱灰的死志） |

## 锚点使用常见误区

| 常见错误 | 正确做法 |
|---------|---------|
| 「这段写的是'他绝望了'四个字，所以强度=10」 | 强度看的是**描写粒度和生理反应细节**，不是作者直接给的情绪标签。如果只写「他绝望了」没有任何肢体/生理/场景细节，撑死=4-5（主观宣告 ≠ 读者体感）|
| 「有眼泪 = 强度 8+」 | 忍住没掉的眼泪（眼眶湿但忍住）= 4-5；掉下来但还能说话=6；失声呜咽/瘫倒=7-8；撕心裂肺+生理失控=9-10 |
| 「第一人称自述很激动 = 强度高」 | 第一人称"我非常生气"的力度其实远不如第三人称的"他指节发白，杯子在手里被捏碎"。永远相信**细节多于自我陈述**。 |
| 「对话里有感叹号 = 强度+2」 | 感叹号是语气标记，不是强度锚点。很多情况下感叹号表示的是亢奋（2-3），而不是强烈情绪。 |
